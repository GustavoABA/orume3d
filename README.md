# Orume 3D

Site de prospecção e vendas da Orume 3D, com foco em impressão 3D sob medida.

## Atualizar o feed

1. Coloque novas fotos em `public/feed`.
2. Use nomes em ordem, por exemplo: `02-chaveiro-personalizado.jpg`.
3. Envie a alteração para o GitHub.

A publicação cria o feed automaticamente. O nome do arquivo vira a legenda do card; não é preciso editar a página.

Formatos aceitos: JPG, JPEG, PNG, WEBP, AVIF e GIF.
